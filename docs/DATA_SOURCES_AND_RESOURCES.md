# 岐黄盾 (HerbShield) —— 权威中医药数据源与知识库资产全景

本文档系统梳理《岐黄盾》平台所依赖的**权威法定标准、学术开放数据源、结构化数据集资产**以及未来的扩充接入途径。

---

## 一、 核心法定标准与权威依据

本项目中所有的处方审核、配伍禁忌判定、剂量红线及煎服法规范，均严格遵循国家现行中医药法定标准与权威著作，绝非网上随意抓取的杂乱信息：

| 规范名称 | 颁布机构 / 责任实体 | 系统内对应功能模块 | 法律与学术地位 |
| :--- | :--- | :--- | :--- |
| **《中华人民共和国药典》(2020年版 一部)** | 国家药品监督管理局 / 国家药典委员会 | 毒性中药极量阈值判定、药性归经、饮片规格 | **国家法定最高药品质量标准** |
| **《中医药学高级丛书 · 中药学》** | 中华中医药学会 / 国家中医药管理局统编 | “十八反”、“十九畏”、妊娠禁忌判定 | 行业公认全国临床中药教学与执业药师标准 |
| **《古代经典名方目录》(第一批与第二批)** | 国家中医药管理局 / 国家药品监督管理局 | 经典名方构型库、君臣佐使推演 | 国家法定古代经典名方研发与免临床评价标准 |

## 二、 现有本地已就绪的数据集资产 (`data/` 目录)

平台在 `data/` 目录下已完成清洗与结构化转化的核心数据文件如下：

### 1. `data/herbs_dataset.json`（《中国药典》临床常用中药饮片词典）
* **收录规模**：首批 **61 味** 临床最高频使用中药（涵盖解表、清热、泻下、温里、化痰、补益等全部 17 个中医功能大类）。
* **字段结构**：
  * `herb_name`: 药材规范名称（正名）
  * `pinyin`: 汉语拼音
  * `aliases`: 炮制异名与别名列表（用于实体归一化，如 `["生附子", "黑顺片", "熟附子"]`）
  * `nature` / `flavor` / `meridians`: 四气、五味、归经
  * `toxicity_level`: 法定毒性级别（无毒 / 微毒 / 有毒 / 大毒）
  * `max_dosage`: 《中国药典》最高常规单剂量（克）
  * `efficacy`: 功效与主治
  * `contraindications`: 使用禁忌及配伍禁忌说明
  * `decoction_method`: 煎煮法规范（先煎 / 后下 / 包煎 / 烊化 / 另煎 / 常规水煎）

### 2. `data/formulas_dataset.json`（国家经典名方配伍库）
* **收录规模**：收录包含《伤寒论》《脾胃论》《太平惠民和剂局方》等传世经典名方（如麻黄汤、桂枝汤、补中益气汤、四逆汤、当归补血汤、四君子汤、四物汤、六味地黄丸、逍遥散、血府逐瘀汤等）。
* **核心字段**：
  * `formula_name`: 方剂名称
  * `source_book` / `author`: 出处著作与创方医家
  * `category`: 治法分类
  * `composition`: 药味及标准剂量列表（含君臣佐使角色标记）
  * `indications`: 主治病机证候

### 3. `data/classics_rag_corpus.json`（古籍切片与现代分子药理 RAG 语料）
* **收录规模**：精选 **7 组** 高频深层推演知识切片。
* **特色内容**：不仅包含《本草纲目》《金匮要略》原文考证，还融合了**现代分子药理学机制**（如甘草酸抑制小肠 P-糖蛋白导致甘遂二萜毒素吸收激增、附子双酯型乌头碱水解机制、细辛黄樟醚中枢麻痹毒理），并提供**安全替代药方建议**。

### 4. `db/seed_data.sql`（PostgreSQL / 关系数据库一键导入脚本）
* 与 `db/schema_pgvector.sql` 完全对应，执行后即可将上述全部数据一键灌入 `tcm_herb_dict` 与 `tcm_formula_catalog` 表中。

## 三、 学术界与开源领域可用数据源扩展池（储备资源）

若未来需要进一步将中药条目从当前的几百味扩展至数千味，或做网络药理学靶点推演，可直接对接以下开放学术数据库：

1. **TCMSP (Traditional Chinese Medicine Systems Pharmacology Database)**
   * **研发团队**：西北大学王永华教授团队
   * **数据资产**：收录 499 种中草药、29,384 个化学小分子成分、3,311 个作用靶点和 837 种疾病关联网络。
   * **开放性**：提供公开学术检索接口，可导出分子成分及 ADME 药代动力学参数（如口服生物利用度 OB、类药性 DL）。
2. **SymMap (中医药与现代医学症候关联数据库)**
   * **研发团队**：北京中医药大学 / 中国医学科学院
   * **数据资产**：整合中药、中药成分、中医证候、现代医学表型与疾病基因的多维异构网络。
3. **中国中医科学院·中医药传统知识保护数据库**
   * **数据资产**：收录历代名老中医经验处方与各省地方习用药材炮制规范。
4. **HuggingFace & GitHub TCM Open Datasets**
   * 如 `wenge-research/YTrans`、`TCM-NER` 等开源中医实体识别与知识图谱数据集，可用于进一步扩充 OCR 实体识别的字典外新词发现。

## 四、 数据与架构的协同方式（Neuro-Symbolic 数据分流）

在《岐黄盾》平台中，数据并不是混在一起的，而是根据“安全红线”与“认知推演”进行了分流：

```
                    ┌── 1. 结构化法定规则数据 (十八反/极量) ──> Java 内存哈希池 ($O(1)$ 0.1ms 强行一票否决)
                    │
权威中医药数据源 ───┼── 2. 实体元数据与历史记录 (药材/方剂/审计) ──> PostgreSQL 关系表 (ACID 事务与合规留痕)
                    │
                    └── 3. 古籍论述与现代分子药理文本 ──────> pgvector 向量库 (HNSW 向量相似度语义召回)
```

通过这一数据架构，平台既守住了医疗安全红线，又赋予了大模型深厚的古籍与现代科学推演底蕴。
