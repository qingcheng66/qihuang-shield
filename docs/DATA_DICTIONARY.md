# 岐黄盾 (HerbShield) —— 中医药核心规则与数据字典

本文档收录系统内置的核心配伍禁忌、药典剂量红线、特殊煎服法与中医九种体质对应规则。

---

## 一、 中药配伍安全红线（十八反与十九畏）

### 1. 十八反（相反：同用产生剧毒或严重副作用）
*   **甘草** 反：甘遂、大戟、海藻、芫花
*   **乌头**（川乌、草乌、附子） 反：半夏、瓜蒌（栝楼）、贝母（川贝母、浙贝母）、白蔹、白及
*   **藜芦** 反：人参、党参、沙参、丹参、玄参、苦参、细辛、芍药（白芍、赤芍）

### 2. 十九畏（相畏/相恶：相互牵制削弱药力或增加毒性）
*   **硫黄** 畏 朴硝
*   **水银** 畏 砒霜
*   **狼毒** 畏 密陀僧
*   **巴豆** 畏 牵牛子
*   **丁香** 畏 郁金
*   **川乌、草乌** 畏 犀角（水牛角）
*   **芒硝** 畏 三棱
*   **官桂（肉桂）** 畏 赤石脂
*   **人参** 畏 五灵脂

## 二、 常见毒性中药药典剂量上限（单剂极量）

| 药材名 | 药典常用剂量 | 警戒红线 | 风险提示 |
| :--- | :--- | :--- | :--- |
| **细辛** | 1g ~ 3g | > 3g | “细辛不过钱”，超量易致呼吸抑制及马兜铃酸蓄积肾毒性 |
| **附子（制）** | 3g ~ 15g | > 15g | 乌头碱具有心脏毒性，必须先煎 1~2 小时 |
| **生半夏** | 常用制半夏 3~9g | 生品有毒 | 刺激咽喉黏膜，必须特殊炮制并久煎 |
| **朱砂** | 0.1g ~ 0.5g | > 0.5g | 汞中毒风险，忌火煅，只宜冲服或水飞 |

## 三、 特殊煎服法规则库

| 煎服类型 | 典型代表中药 | 煎服规范说明 |
| :--- | :--- | :--- |
| **先煎** | 附子、川乌、生石膏、磁石、鳖甲、龟甲 | 矿物介壳类需先煎煮 30~60 分钟以释出有效成分或降低毒性。 |
| **后下** | 薄荷、砂仁、沉香、肉桂、大黄（泻下） | 含挥发油或不耐热成分，在出锅前 5~10 分钟放入。 |
| **包煎** | 旋覆花、车前子、辛夷、蒲黄 | 绒毛刺激咽喉或黏性易糊锅者，需用纱布包扎后煎煮。 |
| **烊化（溶化）**| 阿胶、鹿角胶、龟甲胶、蜂蜜 | 胶质药物单煎易糊，宜在煎好的汤药中趁热冲服搅拌溶解。 |

## 四、 中医九种体质与舌象特征映射矩阵

根据中华中医药学会《中医体质分类与判定》标准：

| 体质类型 | 典型舌质 | 典型舌苔 | 兼夹特征 | 调摄食疗与名方建议 |
| :--- | :--- | :--- | :--- | :--- |
| **平和质** | 淡红舌 | 薄白苔 | 舌体大小适中，无齿痕 | 饮食有节，玉屏风散调护 |
| **气虚质** | 淡白舌 | 薄白苔 | 舌体胖大，边有齿痕 | 黄芪、党参、山药，补中益气汤 |
| **阳虚质** | 舌淡白而胖嫩 | 白滑苔 | 舌面水滑，畏寒肢冷 | 当归生姜羊肉汤，金匮肾气丸 |
| **阴虚质** | 舌红或绛红 | 少苔或无苔（剥苔） | 舌面干燥，或有裂纹 | 百合、麦冬、沙参，六味地黄丸 |
| **痰湿质** | 舌体胖大 | 白厚腻苔 | 黏腻不易刮除 | 茯苓、陈皮、薏苡仁，二陈汤 |
| **湿热质** | 舌质偏红 | 黄厚腻苔 | 口苦口臭，面部出油 | 赤小豆、绿豆、荷叶，甘露消毒丹 |
| **血瘀质** | 舌质青紫或有瘀斑 | 薄白或薄黄 | 舌下络脉曲张怒张 | 玫瑰花、山楂、桃仁，血府逐瘀汤 |
| **气郁质** | 舌质偏红或淡红 | 薄白苔 | 舌边微翘，胸闷喜叹息 | 佛手、柴胡、玫瑰花，逍遥散 |
| **特禀质** | 舌质多变 | 多见地图舌或剥苔 | 易过敏，喷嚏皮疹 | 乌梅、防风，过敏煎 |
